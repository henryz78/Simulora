## 3. Scope and inventory

The package contains 37 authored templates, T01–T37, covering beginner scenarios, mechanism tests, medium/long simulations and dynamic systems such as ecology, generations, economy, law, migration, civilization, recovery, investigation, alliances, community governance, social networks, education and research.

Recurring mechanism pattern: clear goals, constraints, NPC motives, multiple paths, resource flow, visible consequences, causal chains and failure that transforms world state rather than merely ending play. Its reference object model includes premise, initial state, character/location/faction cards, relationship graph, secrets, conflicts, economy/resources, event decks and simulation hooks.
