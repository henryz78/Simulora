# World Creator Complete Flow

Status: `PARTIAL / TESTED`

Entry is global Create → World or an existing World → Edit. Creator auto-saves Draft, supports cover crop/upload, theme, metadata/tags/Markdown, visibility, remix permission, Characters, player setup fields, genre templates, Apps/configuration, system/win-lose/opening text, advisor/console, live desktop/mobile preview, layout designer, discard Draft, version publish and delete danger zone.

Publish vN opens a changelog modal; new starts use latest version and old saves receive optional update. Preview is Turn 0 and read-only.
