### Findings, without redesign

1. **Short-run identity/continuation is promising, not qualified.** Distinct
   motives/knowledge reached the actual model. Continuation drew on recorded
   detail and both Characters used corrected truth. The minimized comparison
   already carries Character motives/known facts, so this is not proof that the
   new context alone caused character differentiation. One sample per arm, fixed
   order and no seed control cannot prove a systematic quality improvement.
2. **Real agency-guard false positive.** The enriched Tavi sentence places a
   conditional “If you wave…” before “Tavi says…”. The sentence-wide regex finds
   `you … says` and treats Character attribution as user speech. A direct probe
   of the existing domain function rejects “If you wave them through that dim
   western line right now, Tavi says, they will read it as a bearing.” but accepts
   “Tavi says the western route is unsafe.” Neither asserts an actual keeper
   decision. This is a demonstrated comprehension/availability problem, not a
   mutation/authority bypass. No guard was changed or disabled. Preserve the
   failing original output for a later narrow fix with negative agency tests and
   matching PostgreSQL guard semantics; do not solve it with blanket permission
   for generated user speech.
3. **Effect/confirmation ceiling is tangible.** Tavi's assessment can produce an
   identical before/after fact; Iora's explanation expands the same fact with
   unknowns and requires L3 confirmation. Narrative testing adds log/glass details
   which have no independent typed runtime membership. This does not mean the
   current L3 safety binding is wrong; ordinary conversation and bounded world
   effects still lack their own implemented semantics. RE-3 must address that
   distinction, not just ask for longer prose or remove exact canonical review.
4. **Grounding remains bounded.** Both arms add scene/color and some unsupported
   tide/approach detail. Post-Correction text occasionally treats the superseded
   diagnosis as a historical physical defect, or strengthens “no repair recorded”
   into “nothing repaired”. Corrected fact projection is consistent; historical
   epistemic precision is not perfect. No actual model confidence/source validator
   or long-play qualification is established by this experiment.
