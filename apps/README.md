# Production applications

- `web` — responsive React product composition root.
- `api` — versioned JSON/SSE Node composition root.
- `worker` — independently scalable Node worker composition root.

The production application is implemented through the IP-7 World Studio candidate on top of the approved IP-1–IP-6 authority spine. Live model behavior and later lifecycle/release work remain intentionally absent until their authorized phases.

Production apps must not import from `prototypes/`.
