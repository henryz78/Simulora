# Production applications

- `web` — responsive React product composition root.
- `api` — versioned JSON/SSE Node composition root.
- `worker` — independently scalable Node worker composition root.

IP-2 exposes the authoritative World/Draft/Revision/Continuity read spine. Action Truth, Recovery, World Studio and live model behavior remain intentionally absent until their authorized phases.

Production apps must not import from `prototypes/`.
