# P4 World Studio — Direction Exploration Spec

Status: `THREE-DIRECTION GATE`

P4 is a high-fidelity comprehension prototype for a player-first, continuity-first World Studio. It is not a production creator application, backend, runtime, schema editor or revival of the discarded Manus P4. The primary user is an adult participant who has already reached a playable Greyhaven world and now wants to make it more intentional without becoming a systems engineer. The principal flow is therefore not “configure everything, then publish.” It begins with a world that already works, shows the smallest playable core, lets the user add one meaningful layer whose effect on play is understandable, and exposes advanced depth only when the user deliberately asks for it.

All directions must communicate the same four truths. First, Greyhaven Revision R-03 is playable now. Second, the creator is editing a mutable draft that may become Revision R-04. Third, R-04 is only a World Revision proposal until reviewed; preview text or draft changes are not authoritative world state. Fourth, the active Personal Continuity remains pinned to R-03 and is not silently modified by editing, reviewing or creating R-04. No direction may imply automatic adoption, merge or migration into an existing Continuity.

The shared content includes a playable core—premise, first situation, essential character Maren and participation/boundary contract—followed by meaningful structure such as Maren’s motive, a harbor constraint and a consequence chain. Optional depth may include stable facts, contextual knowledge, dynamic state and goal framing, but it must appear unopened or secondary by default. Creator Templates remain mechanism reference only; the UI must be organized by effect on play, not by template IDs, engine objects, database tables or hidden prompt fields.

The primary comprehension question is: “Can I improve this world while correctly explaining what is playable, what is only a draft, and what happens to my existing Continuity?” The direction should let a reviewer identify the current playable revision, add or inspect meaningful structure, understand the proposed effect on future play, and verify that the current Continuity remains unchanged. A later full P4 flow may include review, playability checks and creation of an immutable revision, but these direction drafts should not pretend to implement persistence or real revision creation.

Visual continuity should inherit Quiet Observatory without turning World Studio into a settings dashboard. Use readable serif display type, restrained amber signals, moon-paper or field-document surfaces, and calm spatial hierarchy. Desktop is shown at 1440×900. Mobile transformation will be designed after a direction is selected; the selected grammar must support a sequential mobile order: current playable truth → chosen authoring layer → revision boundary → safe return. No core meaning may depend on hover, animation, a large image or color alone.

The three directions deliberately vary interaction form rather than merely changing colors: a scene-adjacent living draft, an editorial fieldbook, and a causal constellation. Each uses the same Greyhaven content and the same authority semantics. The evaluation criteria are comprehension, progressive disclosure, emotional continuity with P1/P2/P3, resistance to dashboard/developer-tool drift, and readiness to deepen into a clickable P4 slice.
