## Implementation boundary

- P4 remains a comprehension prototype, not product runtime or persistence.
- The current playable world stays the first layer and remains reachable at all times.
- Meaningful structure is entered progressively and described by effect on play.
- Revision review must state proposal status, affected future revision and unchanged current Continuity.
- No creator dashboard, developer console, setup wizard, complex causal graph, backend, database or production component library is introduced.
